# 🌐 Web App Tester Skill

A comprehensive AI skill that transforms any AI agent (Gemini, Claude, GPT) into a **professional web application QA tester and security auditor**.

## 🎯 What This Skill Does

When loaded by an AI agent, it forces the agent to perform a **13-phase exhaustive analysis** of any web application codebase, covering:

| Phase | Focus |
|-------|-------|
| 1 | Architecture Review (rendering strategy, routing, bundle) |
| 2 | UI/UX & Responsive Testing (320px to 4K, WCAG accessibility) |
| 3 | Logic & Functional Testing |
| 4 | **Security Audit** (XSS, CSRF, CORS, CSP, cookies + mandatory web search) |
| 5 | Performance & Core Web Vitals (LCP, INP, CLS) |
| 6 | Browser & Device Compatibility |
| 7 | API & Network Resilience |
| 8 | State & Data Management |
| 9 | Error & Crash Prevention |
| 10 | Final Delivery + **Fresh-Eyes Re-Analysis** |
| 11 | Structured Remediation (with Hacker Mindset R6 verification) |
| 12 | SEO & Commercial Readiness (payments, GDPR, analytics) |
| 13 | **Pre-Delivery Sentry Validation** |

## 🛡️ Anti-Laziness Features

- **91 minimum code citations** required across all phases
- **Mandatory web search** for current-year vulnerabilities
- **Fresh-Eyes re-analysis** with 4-layer reminder system
- **Hacker Mindset R6** post-fix verification
- **Cross-Reference Matrix** — proves every file was examined

## 🔧 Supported Frameworks

React, Next.js, Vue, Nuxt, Angular, Svelte, SvelteKit, Astro, Remix, Solid, Gatsby, jQuery, PHP/Laravel Blade, Django Templates, Rails ERB, ASP.NET Razor

## 📦 How to Use

1. Load this skill folder into your AI agent's skill/plugin system
2. Tell the agent: "Run the web app tester skill on my project at [path]"
3. The agent will execute all 13 phases automatically with stop points
