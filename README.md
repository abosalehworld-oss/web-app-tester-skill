## ✨ What This Skill Does

When installed, your AI agent becomes a **professional web app QA engineer & security auditor** capable of:

- 🏗️ **Architecture Review** — Rendering strategy (CSR/SSR/SSG), routing, components, bundle config
- 🎨 **UI/UX & Responsive Testing** — 320px to 4K, forms, WCAG 2.1 accessibility, dark mode, animations
- 🧠 **Logic & Functional Testing** — Validation, CRUD, auth flow, state machines, real-time features
- 🔒 **Security Audit** — XSS, CSRF, CORS, CSP, cookies, injection, open redirects *(mandatory web search)*
- ⚡ **Performance & Core Web Vitals** — LCP, INP, CLS, bundle size, images, caching
- 🌍 **Browser & Device Compatibility** — Chrome, Firefox, Safari, Edge, mobile browsers, PWA, i18n
- 🌐 **API & Network Resilience** — Centralized client, retry logic, loading states, offline mode
- 💾 **State & Data Management** — Redux/Zustand/Pinia, URL state, localStorage, form state, cross-tab
- 🛑 **Error & Crash Prevention** — Error boundaries, null safety, route errors, third-party failures
- ✅ **Final Delivery + Fresh-Eyes Re-Analysis** — Executive summary, cross-reference matrix, mandatory second pass
- 🔧 **Structured Remediation (Phase 11)** — Sprint-based fixes with Hacker Mindset R6 post-fix verification
- 🔍 **SEO & Commercial Readiness (Phase 12)** — Meta tags, Open Graph, payments, GDPR, analytics, PWA *(mandatory web search)*
- 🛡️ **Pre-Delivery Sentry Validation (Phase 13)** — Sentry setup per framework, browser matrix testing, deployment verdict

| **React** | `package.json` (react dep), `src/App.jsx/tsx` |

| **Vue** | `package.json` (vue dep), `*.vue` files |
| **Nuxt** | `nuxt.config.ts/js`, `pages/`, `composables/` |

## 🛡️ Anti-Laziness Enforcement System

This skill is engineered to **force thorough review** even from AI agents that tend to skip steps.

### 1. Proof-of-Work Citations (91 Minimum)
Every finding MUST include exact file path, line numbers, and copied code snippet.

### 2. Mandatory Phase Gates (13 Gates)
Each of the 13 phases has a structured checklist that must be completed with evidence before the AI can proceed.

### 3. Mandatory STOP Points
After each phase, the AI MUST output a structured report and wait for acknowledgment.

### 4. Cross-Reference Verification Matrix
The final phase requires a matrix proving every file was examined — if any phase shows 0 files, the review is invalid.

### 5. Fresh-Eyes Re-Analysis (4-Layer Reminder)
After all phases, the AI performs a second independent pass — proven to catch Critical bugs missed on first pass.

### 6. Hacker Mindset R6
After every fix, the AI verifies from an attacker's perspective that no new vulnerabilities were introduced.
